# HoroscopeToday

HoroscopeToday 是一個用星座、三題選擇與今日心情，產生個人化今日星語的單頁網站。專案希望用簡單、溫暖且不恐嚇的文字，讓使用者花一分鐘整理當下狀態。

## 使用流程

1. 從首頁開始並選擇十二星座之一。
2. 回答社交、決策與能量三題二選一問題。
3. 輸入今日心情，也可以留白。
4. 系統抽出七級籤運並產生今日信箋。
5. 使用者可以分享、複製、儲存圖片或重新開始。

## 主要功能

- 十二星座圓形星盤與選中效果
- 三題二選一問答、進度與切換動畫
- 今日心情輸入，最多 300 字
- 七級籤運：大吉 ＞ 中吉 ＞ 小吉 ＞ 吉 ＞ 末吉 ＞ 凶 ＞ 大凶
- OpenRouter AI 個人化信箋
- AI 失敗時自動改用規則式信箋
- Web Share API 與複製文字備援
- 今日星語 PNG 儲存與背景切換
- 手機響應式排版與減少動畫設定
- 亮色／深色主題
- Buy Me a Coffee Demo，不會扣款或儲存付款資料

## 生成邏輯

規則式信箋依序組合：

```text
星座開場
＋社交傾向句
＋決策方式句
＋今日能量句
＋籤運提醒句
＋收尾句
```

每個星座有兩個開場變化；三題答案各自影響一段內容。籤運採加權抽取，好運較常出現，大凶機率最低。所有文字模組都有安全備援，避免顯示 `undefined`。AI 版本會收到星座、三題答案、籤運與心情；若 API 無法使用，前端仍會立即顯示規則式信箋。

## Edge-case 設計

- 未選星座或未回答目前題目時，下一步按鈕不可使用。
- 問題切換與生成期間會鎖定操作，避免快速連點跳題或重複生成。
- 心情可留白，並使用 `textContent` 顯示，HTML 或 script 只會成為純文字。
- 長文字會自動換行，不會撐破手機版面。
- 分享取消不顯示錯誤；不支援原生分享時改為複製文字。
- 重新開始會清除星座、答案、心情、籤運與信箋。
- 重新整理後從首頁開始，只保留使用者的亮色／深色偏好。

## 技術架構

- 前端：原生 HTML、CSS、JavaScript
- AI API：Cloudflare Worker、OpenRouter
- API Key：只從 Worker 的 `OPENROUTER_API_KEY` 環境變數讀取
- 靜態網站：GitHub Pages

本機執行：

```bash
npm install
npm run dev
```

請在本機 `.env` 或 Cloudflare Worker Secret 設定 `OPENROUTER_API_KEY`，不要把真正的 Key 提交至 Git。

## 團隊分工

- UI／UX：頁面流程、視覺與手機版
- Frontend：單頁切換、狀態、分享與互動
- Logic：星座文字、七級籤運與信箋生成
- API：Worker、OpenRouter 與錯誤備援
- QA：流程、特殊輸入、手機與公開網址測試
- Project：Task List、Demo 與版本管理

## 2～3 分鐘 Demo 流程

1. 說明網站目標，從首頁開始。
2. 選擇一個星座並回答三題，展示選中與切題效果。
3. 輸入一段含特殊符號的心情，展示安全純文字處理。
4. 生成結果，說明籤運、AI 信箋與規則式備援。
5. 展示背景切換、分享或圖片儲存。
6. 按下「我明白了。」回首頁，確認資料已清除。

## 真實 Bug 與修正案例

合併 Coffee 功能後，舊版模擬信用卡視窗被重複加入 `index.html`，開啟網站時產生全畫面遮罩。修正方式是完整移除舊付款表單與重複的 Credits，只保留不收集信用卡資料的 Coffee Demo，並再次檢查頁面中不存在舊欄位。
